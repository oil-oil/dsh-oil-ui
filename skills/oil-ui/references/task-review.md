# 只读评审

上级入口：[Skill 主流程](../SKILL.md)。用户只要评审时，本流程只交付证据、诊断和建议，不修改产品文件，不生成新方向，也不进入制作后的修正循环。

1. 写清评审对象、用户目标、设备与已知约束；只读取相关页面、截图和材料，不通读整个项目。比较已有方案时保持它们现有的内容和范围，不先补齐成自己的设计。
2. 能运行或看图时取得真实证据；不能时明确限制，不把推测写成实际视觉或交互结论。按 [视觉评审派发协议](visual-review.md) 选择适合现有界面或候选方案的评审方式，评审标准由评审者读取，主 Agent 只交接材料。
3. 有隔离且能看图的执行者时，派没有制作历史的评审者；没有则由主 Agent 自检，并在结果中写明“未独立评审”。需要验证主要流程时，按 [轻量 UX 走查派发](ux-review.md) 取得任务走查证据；纯视觉评审不额外走查。
4. 报告按影响排序，写清位置、观察、依据和建议；比较方案时分别说明适配与代价，再给选择建议。交付报告后停止，不修正、不实现建议，也不顺便扩展任务范围。
